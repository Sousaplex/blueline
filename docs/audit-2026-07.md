# Blueline codebase audit — 2026-07-27

Four parallel deep audits (engine/toolkit · frontend · security · packaging/tests), every
finding verified against code at `file:line`. Deduped and ranked here. Version at audit
time: 0.21.1 (layer-model overhaul landed; sources/brand agent tools in progress).

Legend: **P0** fix before wider release · **P1** should fix soon · **P2** backlog.
Effort: S (<1h) · M (half-day) · L (day+).

## Phase 1 — Security P0s (before any wider distribution)

The app is currently safe-ish only because it runs on a trusted laptop. These five make it
safe by construction. All are in the bridge/Electron shell; none touch the editor UX.

| # | Finding | Where | Fix | Effort |
|---|---------|-------|-----|--------|
| S1 | **Bridge binds 0.0.0.0, no auth, CORS `*`** — any website the user visits (or any LAN peer) can read workspace files, rewrite page.html, start agent runs (burning API credits), and drive git with the user's creds | `server.ts:1313` (listen), `:757` (ACAO), `:787` (preflight) | `listen(port, "127.0.0.1")`; random session token passed via env to renderer + MCP, required on every route; drop `ACAO:*`; reject non-localhost `Host` (DNS-rebinding) | M |
| S2 | **`/api/open` + `/api/workspace` accept any absolute path** → `/files/*` becomes arbitrary file read (`~/.ssh`, saved keys); also `mkdirSync`s junk into the target | `server.ts:838`, `:1081`; `project.ts:107` | Only slugs `^[a-z0-9-]+$` under `workspace.projectsDir`; `realpathSync` containment check; never mkdir in unvalidated paths | S/M |
| S3 | **`/api/git/clone` URL injection = RCE** (`ext::sh -c …`, `--upload-pack=`) — the URL regex exists in `gitConnect` but not `gitClone` | `server.ts:1295` → `git-sync.ts:121` | Same regex + reject leading `-`; `git -c protocol.ext.allow=never -- <url>`; constrain dest | S |
| S4 | **Generated page.html executes same-origin with the app** — live-edit iframe has no `sandbox`, no CSP anywhere; a `<script>` the agent copied from a fetched site can call `parent.blueline.openPath(...)` (launch arbitrary local app), `setApiKeys`, or exfiltrate via the open bridge | `PreviewPane.tsx:1516`, `main.ts:220`, `preload.ts:3` | `sandbox="allow-same-origin"` (no scripts; editor keeps contentDocument) + `CSP: script-src 'none'` header on `/files/*`; gate `openPath/reveal` to workspace paths | M |
| S5 | **Print/export window runs page JS** (no preload, but same-origin + network) | `main.ts:139` | `webPreferences: { javascript: false, sandbox: true }` + deny-all window-open handler; also restrict `shell.openExternal` to http(s) (`main.ts:201`) | S |

Supporting P1/P2 security (do opportunistically): SSRF re-check on redirect hops
(`web-fetch.ts:103+`), confine agent write/edit tools to the project dir
(`session.ts:17` — prompt-injection → `~/Library/LaunchAgents` persistence),
imageId regex on upload (`server.ts:1041`), MIME allowlist + `nosniff` on served sources,
request-size caps, don't echo raw error paths cross-origin.

**Verified already-solid (don't re-litigate):** `tagElement` selector grammar,
`setElementProps` CSS whitelist, `safeRelPath`, `/files` traversal checks, no-bash agent,
contextIsolation, keychain custody + `.env` git-scrubbing, ask-before-download updates.

| # | Finding | Where | Fix | Effort |

   This is the layer only a browser can prove (task #77).

## Phase 5 — Architecture cleanups (P2, do while touching those files)

- **server.ts route table + `mutatingPageRoute()` wrapper** (requireProject → snapshot →
  edit → broadcast) — deletes ~15 near-identical blocks and makes C4-class bugs impossible.
- **DOM cache for page-edit** — `loadDom` keyed by (path, mtime) instead of full
  parse+serialize per HTTP call (also stops formatting churn).
- **PreviewPane extraction seams** (no rewrite): `useCanvasZoom`, `useImageGestures`,
  `useCanvasSelection`, and split the 450-line `armLiveEditing` closure into
  `injectEditorStyles` / `installSelectionHandlers` / `installDragHandlers` / `installKeyboard`.
- Unify: one `nextVariant()` (3 divergent copies), one `mergeStyle` (2 copies, both would
  corrupt semicolon-in-value), one `Project.rounds()` (4 scans), `resolveElement` for ALL
  element/image ops (delete/moveBefore still pc-id-only).
- Dead code: `commands/viewer.ts`, `ensureCompiledOrRender` name, `marginTop` plumbing,
  `buildPresscheckTools` name, unused `Move` import, stale geometry doc comments.
- Perf long-tail: `gitStatus` network fetch on every poll (cache), relaunch crashed
  Chromium (`isConnected()`), promise-dedupe `proofPages`, stream file responses.
- UX long-tail: idempotent layer-row click (currently toggles-off the selected image),
  toast when legacy-compile retries exhaust, batch delete = one undo step,
  `saveSource` error toast, ⌘-wheel zoom dead over the iframe.
